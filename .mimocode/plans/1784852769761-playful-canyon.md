# Análise Visual + Conceito de Cartão de Visita — Desysis

## 1. Identidade Visual do Site

### Paleta de Cores

| Elemento | Cor | Uso |
|---|---|---|
| **Fundo principal** | `#09090b` (preto quase absoluto) | Background do body |
| **Fundo secundário** | `#18181b` (cinza muito escuro) | Seções alternadas (Sobre, Projetos, Footer) |
| **Fundo terciário** | `#27272a` (cinza escuro) | Bordas, elementos sutis |
| **Texto principal** | `#fafafa` (branco quase puro) | Títulos, textos principais |
| **Texto secundário** | `#a1a1aa` (cinza médio) | Descrições, parágrafos |
| **Texto muted** | `#71717a` (cinza apagado)** | Labels de formulário, footer |
| **Acento principal** | `#a855f7` (roxo vibrante)** | Botões, ícones, destaques |
| **Acento claro** | `#c084fc` (roxo pastel)** | Tags, labels de serviço |
| **Acento escuro** | `#9333ea` (roxo profundo)** | Variação do acento |

### Gradientes

- **Gradiente 1** (principal): `#a855f7` → `#6366f1` → `#3b82f6` (roxo → indigo → azul, 135°)
- **Gradiente 2** (secundário): `#f472b6` → `#a855f7` (rosa → roxo, 135°)

### Tipografia

- **Display/Títulos**: Space Grotesk (geometric sans-serif, peso 700-800, tracking -2px)
- **Corpo**: Inter (humanist sans-serif, peso 300-900)
- **Hierarquia**: Títulos usam clamp(2.5rem, 6vw, 4.5rem) no hero, clamp(2rem, 4vw, 3rem) em seções

### Estilo de Design

- **Glassmorphism**: Fundos semi-transparentes (`rgba(255,255,255,0.03)`), bordas translúcidas, backdrop-filter blur
- **Bordas arredondadas**: 8px (sm), 12px (md), 20px (lg)
- **Sombras sutis**: Apenas em botões e cards com hover
- **Orbs decorativas**: Dois círculos fixos com gradiente (roxo e indigo) em opacity 0.12
- **Animações**: Fade-up e fade-left no scroll, staggered entrance nos cards
- **Espaçamento generoso**: 120px padding vertical nas seções

### Personalidade

O site transmite **sofisticação técnica** — é minimalista mas ousado. O preto profundo com roxo vibrante cria contraste alto que comunica inovação. O glassmorphism adiciona profundidade sem pesar. O gradient roxo→indigo→azul é a assinatura visual — aparece no título, botões, números dos cards e scroll-to-top.

## 2. Conceito: Cartão de Visita — Frente e Verso

### Especificações Técnicas

- **Tamanho**: 9cm × 5cm (padrão cartão de visita)
- **Impressão**: Frente e verso (double-sided)
- **Acabamento sugerido**: Fosco com laminação soft-touch + spot UV no gradiente

### Por que isso é mais que uma folha de papel?

| Elemento | Utilidade |
|---|---|
| **QR Code na frente** | Escaneia → salva contato (vCard) ou abre portfólio. Zerodigitação. |
| **Gradiente no verso** | Memorabilidade visual — quem recebe nunca confunde com outro cartão |
| **Padrão geométrico** | Comunica "sistemas" e "construção" sem precisar de texto |
| **Dupla face com propósito** | Frente = dados práticos. Verso = marca e serviços. |
| **Acabamento soft-touch** | Tátil — a pessoa segura e sente a qualidade |
| **Spot UV no gradiente** | Brilho seletivo no verso destaca o gradiente quando inclinado |

### QR Code — O que linkar?

Opções (em ordem de utilidade):
1. **vCard digital** (.vcf) — escaneia e salva nome, email, telefone, site no celular
2. **Linktree/página de links** — portfólio, Instagram, WhatsApp, email
3. **Site direto** — desysis.com com UTM de rastreamento (`?src=cartao`)
